ULabel Demos

Local demo pages served by npm run demo. Run npm run build first to pick up source changes.

Overview

  • live_demo - Annotated street scene with mixed confidences, confidence_card_classes, and hover_card_text. Published to GitHub Pages.
  • single-class - One subtask, one class.
  • multi-class - Several classes and every spatial mode, plus a whole-image subtask.

Features

  • linked-subtasks - Diff / GT / Predictions linked by annotation_link_meta_key: Copy to, Set class in, Delete from, counterpart_class_meta_key.
  • class-focus - focus_active_class and per-class allowed_modes.
  • bitmask-example - Bitmask brush and erase with a reference subtask.
  • box-roi - Main subtask plus a bbox-only ROI subtask.
  • row-filtering-example - FilterDistance: points filtered by distance from polyline rows.
  • read-only - Every subtask read_only, with a toggle.
  • frames - Multi-frame image stack with frame-level annotations.

Data and API

  • resume-from - Loading existing annotations with resume_from.
  • set-annotations - Swapping annotations at runtime with set_annotations, small to large sets and bitmasks.
  • getset - Round-tripping get_annotations / set_annotations.
  • submit-payload - Submit buttons, including edits_only payloads.

Layout and test fixtures

  • offset-container - ULabel inside an offset container.
  • bitmask-e2e - Minimal two-subtask bitmask fixture used by e2e tests.
